### GigShield
**Gig-worker rights and wage-transparency platform**, built for the **NYXORA MREM Hackathon 2026**.

- Underpayment detection and a wage-deficit calculator
- Exploitation index for working conditions
- AI-powered explanations of workers' legal rights

`Next.js` `Supabase` `Groq API` `Tailwind CSS` `Recharts`

[Repository](https://github.com/Srujan-Prabhu-I/gigshield) · [Live Demo](https://gigshield-six.vercel.app)

### SYNTH &nbsp;<sub><img src="https://img.shields.io/badge/research-in%20progress-d29922?style=flat-square" alt="Research in progress" /></sub>
**A multimodal, longitudinal world model for athlete performance**, using a **Joint Embedding Predictive Architecture (JEPA)**.

The goal is to learn how training load, wellness data, and wearable signals relate to an athlete's future state.

- **Research areas:** JEPA · self-supervised learning · representation learning · multimodal and temporal modeling · performance forecasting
- Ongoing research. Not yet published and not a production system.
